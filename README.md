# Kitchen Table

**Status: discontinued.** This project is no longer being worked on.

Kitchen Table was a plan for short, turn-based games that families and friend groups play
together, with an optional AI host. It never got past planning, and no code was written.

The planning documents (architecture, roadmap, game rules and decision records) were removed.
They remain in the git history. To see them, check out commit `c12d953`.
